# 老妈学字

一个帮助长辈学习认字的微信小程序。内置了一些文字，也可以自己**录入**文字来给家里长辈学习，录入身边常用字，点一下字就读出来，一屏只放一课，能看笔顺、能用手在屏幕上写，家人还能把自己的**声音**录进去来辅助学生发音。

学习记录和录音全部留在本机。

## 主要功能

**默认课程 30 课。** 每课 7 个字，一共 210 个字，全课程没有重复。换课要自己点首页的「← 上一课 / 下一课」，隔天不会自动跳到下一课。

**一屏就是这一课的内容。** 首页只放当前这一课的 7 个字，点一下就读出来。学过的字不会消失，可以反复点、反复学。

**家人录入。** 在底部「录入」上按住 3 秒就能进。连着写的字按单字拆开，用空格或逗号隔开就按词保存。录入的内容不会过期，新录入是往上追加。

**家人录读音。** 每个字可以录一段 4 秒的家人声音，播放时优先用家人的录音——长辈最认这个声音。也可以补上常用词、例句、怎么记。

**到期自动复习。** 点过「认识了」的字会排进「复习」页，按 30 分钟到 30 天的间隔到期出现，答对间隔拉长、答错缩短，只列今天该复习的字。

**看笔顺 + 手写。** 逐笔动画回放，然后在田字格里用手指写。可以选「临摹」（底下有浅色字帖）或「空白」（只有格子）。

**已录字词本。** 家人录过、长辈也认识过的字词单独收在一页，点一下就能听到家人的声音。

## 如何使用

### 微信扫码打开

用微信扫一扫：

<img src="README.assets/老妈学字小程序.jpg" width="220" alt="老妈学字小程序码">

小程序已经发布，扫码就能用，不需要注册或登录。

### 长辈学习

1. 打开后点「开始学」。
2. 一个字一张卡：拼音、大字、怎么记。字卡出来约半秒会自动读一遍，点大字可以再听。
3. 认识了点「✓ 认识了」，拿不准点「× 还不熟」。
4. 学完做几道「听一听，选出这个字」，在四个大字里选一个。

选错不扣分、也不重来，只是把正确的那个标出来。刚才点过「还不熟」的字会自动再走一遍。

点「✎ 看怎么写」，可以看这个字的笔顺动画，再切到手写，用手指在田字格里描。

### 家人录入字词和录音

1. 在底部导航「录入」上**按住 3 秒**，屏幕中间会出现 3→2→1 倒计时，中途松手就取消。
2. 输入汉字，点「加入学习」。连着写的按单字拆开；用空格、逗号、顿号隔开就按词保存。
3. 每个字右边三个按钮：**录音**（说完 4 秒自动停）、**补充**（常用词、例句、怎么记）、**拿掉**。
4. 录过音的字按钮会变成「✓ 已录」——再点它是**删除确认**，不是重录。

录入的内容不会过期，新录入是往上追加。不想要的用「拿掉」从今天移走，录音和补充信息会保留。

### 开发者运行

用[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)导入项目根目录（能看到 `app.json` 的那一层），用测试号或自己的 AppID 编译。

项目没有 `package.json`，不需要 `npm install`，运行时不发起任何网络请求。改完课程数据可以跑 `node scripts/check-course.js` 做一次自检。

## 项目结构

只列到目录，每个目录一句话。`不进包` 表示已经写进 `packOptions.ignore`，不会打进小程序安装包。

```text
studyMM_rebuild/
├── app.js / app.json / app.wxss   入口与全局配置（没有 tabBar，底部导航由各页面自绘）
├── pages/                          主包，四个主页面
│   ├── index/                      今天
│   ├── review/                     复习
│   ├── profile/                    已录
│   └── input/                      录入（长按 3 秒进入）
├── study/                          分包：学习流程
│   ├── pages/learn/                认字卡、听音选字、完成页
│   ├── data/phrase-map.js          292 条词组 → 读音文件的映射
│   └── audio/                      292 个词组读音 mp3，约 1.3 MB
├── stroke/                         分包：笔顺与手写
│   ├── pages/write/                笔顺动画与田字格手写
│   ├── data/strokes.js             2988 个字的笔画路径，约 1.7 MB
│   └── utils/stroke-geometry.js    坐标缩放与笔画插值
├── utils/                          复习间隔、本地存储、录音、播放、录入解析等模块
├── data/                           30 课课程、20856 字拼音表、6299 条词表
├── audio-py/                       965 个拼音音节读音 mp3，约 1.3 MB
├── scripts/check-course.js         课程数据自检（不进包）
├── tests/                          单元测试（不进包）
└── README.assets/                  截图与小程序码（不进包）
```

主包只有 4 个页面，学习页和手写页放在 `study` / `stroke` 两个分包里，按需加载，首屏更快。

## 隐私与数据

- 无需注册或登录；学习记录、当天任务、补充内容和家人录音都保存在这台手机的本地存储里。
- 小程序代码里没有任何网络请求，数据不会上传到任何服务器。
- 换手机、清理微信数据或卸载微信，学习记录和录音可能会丢失。
- 家人录音是 16kHz 单声道 mp3，只存在本机，跟着小程序数据一起清理。
- 公开仓库不包含开发者本机配置和用户运行时录音；`project.config.json` 用的是游客占位 AppID。
